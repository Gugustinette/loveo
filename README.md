# Loveo

Loveo est un site de rencontre boostée à l'intelligence artificielle pour vous aider à trouver l'amour.

Notre algorithme de matching est basé sur des données scientifiques et des études de psychologie pour vous aider à trouver la personne qui vous correspond le mieux, à travers un processus juste, éthique et équitable.

## Développement

```bash
# Installation des dépendances
npm install
# Lancement du serveur de développement
npm run dev
```
